# 外卖经营助手 MVP

这是一个面向周边外卖商家的本地经营分析原型。当前版本不连接美团、饿了么等平台账号，也不自动执行改价、退款或发消息操作。

## 启动

在项目目录运行：

```powershell
python -m http.server 4173 --bind 0.0.0.0
```

然后打开：`http://127.0.0.1:4173/`

手机访问时不要使用 `127.0.0.1`。电脑和手机连接同一个 Wi-Fi 或局域网后，在手机浏览器打开：`http://10.11.236.188:4173/`。如果仍然打不开，需要在 Windows 防火墙中允许 Python 接受专用网络的入站连接，或暂时允许 TCP `4173` 端口。

也可以直接双击 `index.html` 使用。数据处理在当前浏览器完成，不会上传到服务器。

## 当前功能

- 加载内置示例订单
- 导入订单 CSV
- 统计销售额、有效订单、平均客单价和退款率
- 绘制每日销售趋势
- 统计热销商品
- 对低分评价和退款原因做分类提示
- 生成可复制的经营日报

## CSV 字段

必填字段：`商品`、`金额`

可选字段：`日期`、`订单号`、`状态`、`评分`、`评价`、`退款`

示例文件见 `sample-orders.csv` 和 `demo-orders.csv`。网站顶部也提供了“下载示例 CSV”按钮。CSV 中带逗号的评价内容需要使用双引号包裹。

## 后续产品化方向

下一步可以接入商家主动导出的真实订单数据，增加毛利分析、套餐建议、差评回复草稿和飞书/企业微信日报推送。平台后台的自动操作应等获得正式接口和商家授权后再做。
